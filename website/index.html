What it does

Fast and hard to break

Up to 32 connections per file, automatic retries, and resume after a restart. An expired link can be swapped without losing progress.

Videos from almost anywhere

YouTube and the sites yt-dlp supports, HLS and DASH streams including encrypted HLS, with a size estimate for each quality.

Torrents built in

Magnet links and .torrent files. Choose the files, download in order, seed if you want to.

On your schedule

Time windows, unmetered connections only, battery and data limits. Power off or suspend when the queue is done.

Works with your browser

The extension sends downloads to LDM with their cookies and finds the videos on a page.

Keeps going in the background

Closing the window doesn't stop anything. You get a notification when a download finishes.

Install

Fedora 43 and 44

Download the package and install it; dnf fetches the rest. A COPR repository with automatic updates is planned.

Download .rpm
sudo dnf install ./ldm-downloader-{{VERSION}}-1.fc44.noarch.rpm

Ubuntu 24.04 and newer, Linux Mint 22

Pick the package for your release. It brings a current yt-dlp, so YouTube works from the start.

Ubuntu 24.04 · Mint 22 Ubuntu 26.04
sudo apt install ./ldm-downloader_{{VERSION}}-1.ubuntu24.04_all.deb

Debian 13

Download the package and install it; apt fetches the rest. Debian 12 can use the Flatpak.

Download .deb
sudo apt install ./ldm-downloader_{{VERSION}}-1.deb13_all.deb

Arch Linux, Manjaro, EndeavourOS AUR coming soon

Until it is on the AUR, build the package from the release's PKGBUILD.

curl -LO {{DL}}/PKGBUILD && makepkg -si

Any other distribution Flathub coming soon

The Flatpak saves to your Downloads folder; choosing another folder in LDM gives it access to that one.

Download .flatpak
flatpak install --user ./ldm-downloader-{{VERSION}}-x86_64.flatpak

Then, once: ldm install-browser-integration for magnet links and the browser extension (as a Flatpak: flatpak run --command=ldm io.github.adiashishz.LDM install-browser-integration). Checksums are in SHA256SUMS.

Browser extension

Clicks on download links go to LDM with the browser's cookies, so sign-in downloads work. On a video page, it lists the streams it found.

Questions

Does it work on KDE, Xfce and other desktops?

Yes. It is a GTK 4 app and runs on any desktop. The tray icon appears where the desktop has a tray.

Why is there a background service?

So downloads keep running when the window is closed. The command line, the browser extension and the window all talk to the same service.

My distribution isn't listed.

Use the Flatpak: it runs on any distribution with Flatpak installed.
